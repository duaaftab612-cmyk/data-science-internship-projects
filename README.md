
#  Data Science Internship Projects

This repository contains a collection of machine learning and data analysis projects completed as part of my data science internship. Each project focuses on applying real-world datasets to build predictive models, perform data exploration, and extract meaningful business insights.

---

##  Projects Included

###  Task 1: Iris Dataset EDA
- Performed exploratory data analysis on the Iris dataset
- Visualized relationships between features (petal length, sepal length, etc.)
- Identified patterns among different flower species

---

### Task 2: Credit Risk Prediction
- Built a classification model to predict loan default risk
- Handled missing values and performed data preprocessing
- Applied Logistic Regression for prediction
- Evaluated model using accuracy score and confusion matrix

---

###  Task 3: Customer Churn Prediction
- Analyzed customer behavior data to predict churn
- Performed data cleaning and feature encoding
- Built Logistic Regression model for classification
- Identified key factors affecting customer retention

---

###  Task 5: Personal Loan Acceptance Prediction
- Used Bank Marketing dataset (UCI repository)
- Performed data exploration on age, job, and marital status
- Built classification model using Logistic Regression / Decision Tree
- Extracted business insights on customer segments likely to accept offers
